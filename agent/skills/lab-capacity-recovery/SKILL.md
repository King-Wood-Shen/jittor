# 经核验的容量恢复

空间预检不足时，先记录目标文件系统的 `df -h`、`df -i`、预计新增空间和运行键。盘点候选文件的大小、来源、引用者与正在运行的作业；同一共享目录中的其他项目和代理数据不能因路径相近而归入本次清理。

只将以下文件列入删除白名单：与保留副本逐字节或校验和一致的重复副本；或者已确认无人引用、后续无需复验、可由已保存的输入与脚本恢复的临时产物。对每项记下运行键、绝对路径、校验方式与结果、保留副本或可恢复来源、无活动作业引用的依据。只有摘要时不能推断原始证据可恢复。

保留唯一模型权重、必要 checkpoint、原始日志、结果矩阵、复验脚本、在用缓存，以及其他项目或代理的数据。无法确认归属、引用或恢复来源的文件不进入白名单。

删除前把明确的路径白名单和实际删除命令写入本次运行的 state 记录；逐项执行，不使用通配符清理整棵目录。记录删除文件的已分配字节数和删除前后的文件系统可用量；两者可能因共享文件系统计量而不同。最后重新运行空间预检，容量仍不足时停止该运行并报告缺口。此流程只授权删除已通过上述核验的白名单文件，不扩大到清理其他数据。
