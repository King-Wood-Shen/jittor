The compatibility method now draws integer-valued chunks on the tensor's actual device, preserving CPU and CUDA RNG separation. Worker probe and directed regression job 23452 passed four tests for CPU int64/float32 and CUDA int64, with shim fallback zero. This repair did not cause the GKD RNG snapshot to change; the prior assertion was a verifier error, separate from the genuine `random_` defect.
